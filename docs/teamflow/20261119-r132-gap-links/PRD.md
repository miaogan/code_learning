## 2. 实现要点

### 2.2 深链构造收敛到纯函数层 `lib/gapLinks.ts`

- `roleFitInterviewHref(roleFit)`：`first_fix` 去重取前 3（顺序 = 后端口径，AC-20 继承不重排）→ focus；方向必须命中 `questionDirections.DIRECTIONS` 闭集否则不写；`first_fix` 推不出 → 空串（调用方不渲染，**宁可不给入口不给死链**）。

- `wrongDirectionsOf`：本页错题方向去重 + 闭集过滤（保持首现顺序）。
- 7 例测试覆盖：编码后断言、上限截断、闭集外回空。
