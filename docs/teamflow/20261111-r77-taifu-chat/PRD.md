# r77 · 太傅对话（只读站内档案的问答）

## 背景

r76 交付了太傅的悬浮壳，面板上写着「问答接口接入中」。本轮把这句话兑现：
用户问一句，太傅读**他自己的**站内记录，给出带出处的回答。

用户原始需求是「通过对话的方式让 AI 分析用户的数据」。这里有一个产品判断必须先钉死：
**「分析我的数据」不等于「替我改数据」**。太傅是参谋，不是执行器——
它只读、只解释、只指向站内记录；不改画像、不重排计划、不自动投递、不写任何业务表。

## 目标

> 问一句站内的事，得到的回答里每个结论都能点回原始记录；数据不够就直说不够。

三条可检验的用户结果：

- 在报告页问「我最近为什么掉分」，回答能引用到具体的报告与测评记录，而不是泛泛说「多练习」。
- 问「先补什么」，回答给的顺序能对上画像短板与错题分布，而不是通用学习路线。
- 没上传简历、没做过测评的新用户点开，看到的是「先去做什么」，而不是编出来的分析。

## 用户故事

- 作为刚看完诊断报告的用户，我想就地追问「这条短板具体差在哪」，不想再切页面重新描述背景。
- 作为做过几次笔试的用户，我想问「最近两次分数为什么差这么多」，希望它指向具体场次。
- 作为准备面试的用户，我想让它把项目要点讲成「面试官能追问的证据」，而不是替我编造项目。
- 作为新用户，我点开太傅时被告知「先上传简历」，而不是收到一段关于我的假分析。

## 范围

| 能力 | 本轮 | 说明 |
| --- | --- | --- |
| 多轮对话（默认线程） | ✅ | 服务端保存最近消息，作为下一轮的上下文 |
| 档案摘要（画像 / 报告 / 测评 / 练习 / 学习） | ✅ | 由服务端从库里读，不信任前端传的材料 |
| 引用白名单 | ✅ | 模型只能引用摘要里出现过的站内路由，越界即丢弃并计数 |
| 清空对话 | ✅ | 只删对话记录，不动任何业务数据 |
| 写操作（改画像 / 生成报告 / 投递） | ❌ | 参谋不执行，避免「AI 改了我的档案」这类不可解释后果 |
| 多线程 / 命名会话 | ❌ | 单人自用，一条线程够用 |
| 教程语料检索 | ❌ | 教程正文只在前端，服务端取不到；本轮引用到章级路由为止 |

## 验收标准

- [ ] **AC-1 有据可答**：已上传简历（或有测评 / 练习 / 学习记录）的用户提问，返回中文回答，`materials_used > 0`。
- [ ] **AC-2 引用可核对**：回答中的引用逐条是站内路由（`/profile`、`/report`、`/history`、`/practice`、`/learn`），点击可跳到对应页面；不在白名单的引用被丢弃并计入 `dropped_citations`。
- [ ] **AC-3 新用户不编造**：完全没有站内记录时**不调用模型**（零成本），返回中文指引「先上传简历 / 先做一次测评」，`materials_used = 0`。
- [ ] **AC-4 问句校验**：空问句、纯空白、超长问句都不进模型；空问句返回中文提示，超长按 200 字截断。
- [ ] **AC-5 多轮上下文**：同一账号连续提问，第二轮能接着上一轮（服务端取最近 6 条消息进提示词）；不同账号互不可见。
- [ ] **AC-6 会话可恢复与可清空**：重新打开面板能读回历史消息；清空后列表为空且不影响画像 / 报告 / 测评 / 练习数据。
- [ ] **AC-7 只读承诺**：除 `taifu_messages` 外不写任何表；不改画像、不生成报告、不改学习进度。
- [ ] **AC-8 失败可见**：模型不可用（未配 Key / 上游失败）走既有中文错误，前端在面板内给原因与「重试」，不静默失败、不把失败渲染成空回答。
- [ ] **AC-9 额度与超时**：走 `user_ai` 的 `light` 档，复用既有每日配额与 `AI_KEY_REQUIRED` 网关；专用超时 120s，前台不重试。
- [ ] **AC-10 面板可用性**：发送中禁用输入并给「太傅正在看记录…」；回答渲染保留换行；引用为可点链接；面板可滚动到底；≤640px 底部面板内同样可完成一轮问答。
- [ ] **AC-11 不回归**：既有单测与构建全绿；r76 的拖拽 / 位置记忆 / 层级行为不变。

## 边界与口径

- 引用是**路由级**而非段落级：太傅不会伪造教程锚点，也不会引用不存在的报告 id。
- 回答长度上限 1200 字，段落数不限；超长截断并保留省略号。
- 会话保留最近 200 条（服务端裁剪），超出按时间淘汰最旧。
- 「太傅改不了任何东西」写进面板脚注，且服务端确实没有任何写业务表的路径。
