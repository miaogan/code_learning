# r75 · 作答不丢与会话打断（前端体验补洞）

## 背景

站在用户视角走查前端（HEAD `82bd83b`，18 个页面全读）后确认：功能闭环完整，问题集中在**边界时刻**——
用户已经投入时间，却因为一次刷新、一次后退、一次登录过期，投入归零；或者失败了却没有任何提示与出口。

本轮只做其中「会直接丢东西 / 会走进死路」的一批，不新增功能、不动 HTTP 契约、不碰 r69–r74 刚定的视觉。

四个已复现的事实：

1. **笔试作答只在内存**（`ExamPage.tsx:70`）。`:179-203` 只拦 `beforeunload` 与站内 `<a>` 点击；
   浏览器后退 / 手机侧滑返回是 SPA 路由变化，两者都不触发。退出即全丢，回来从零开始。
2. **401 静默踹回登录页**（`state/auth.ts:46` + `App.tsx:101`）。整棵树被换掉，没有一句解释；
   重新登录后 URL 还在，页面状态已重来。
3. **未知路由无兜底**（`App.tsx:165-183` 无 `path="*"`）。旧书签或拼错地址 → 顶栏侧栏都在、主区全空。
4. **战绩筛到 0 条成死路**（`HistoryPage.tsx:55,101`）。筛选条被包在 `total > 0` 里，
   只考过面试的人点「笔试」后筛选 chip 消失、无法切回，只能刷新。

另有一条同源问题：**面试正在写的那段回答不持久**（`InterviewPage.tsx:100` 纯 state）。
服务端已答的题能续（有 `sc.interview.<userId>` 锚点），但没提交的 300 字刷新即消失。

## 目标

> 任何一次「非主动放弃」的打断，都不该让已投入的作答归零；任何一次失败或死路，都要有一句话和一个出口。

三条可检验的用户结果：

- 答题过程中刷新、后退、会话过期重登，回到页面时**原卷、已答、计时**都还在。
- 登录页能说清「为什么把你送到这里」。
- 走到空结果或错地址时，**有解释、有按钮**，不需要刷新页面自救。

## 用户故事

- 作为正在做笔试的用户，我答到第 8 题时手机锁屏、页面被系统回收，回来能接着答，而不是重做 12 题。
- 作为面试到一半的用户，我写了 300 字还没提交，手滑刷新后那段文字还在。
- 作为会话过期的用户，我知道是登录过期而不是系统坏了，重新登录后能回到刚才的位置。
- 作为只考过面试的用户，我点「笔试」看到「还没有记录」，并且能一键切回全部。

## 验收标准

- [x] **AC-1 笔试可恢复**：作答中刷新（F5）、站内离开后再进「科考」、401 重登后回到 `/exam`，均恢复同一 `run_id` 的卷面与全部已答，未答保持未答。
- [x] **AC-2 计时连续**：恢复后显示的本卷用时与恢复前连续（不再从 0 开始），并与服务端 `elapsed_s`（按 `started_at` 墙钟计算）同量级。
- [x] **AC-3 恢复有提示**：恢复成功时页面顶部有一行「已恢复你上次未提交的作答（HH:MM 保存）」，可关闭，不遮挡作答。
- [x] **AC-4 过期与脏数据不打扰**：超过 24 小时、结构不合法、题目 id 与卷面对不上，一律丢弃并只提示一次「上一份未提交的作答已过期 / 无法恢复」；不恢复半个卷子。
- [x] **AC-5 生命周期干净**：提交成功后草稿立即清除；重新出卷成功即覆盖旧草稿；不出现「已提交还能恢复」的假象。
- [x] **AC-6 账号隔离**：草稿按 `user_id` 分键；同一浏览器换账号看不到上一位用户的卷面与作答；登出不清草稿（重新登录仍可续）。
- [x] **AC-7 面试草稿**：单题回答编辑中刷新 / 切页回来，文字仍在（上限 `MAX_ANSWER_CHARS = 800`）；提交成功、切到下一题、提前结束、会话 404 时清除对应草稿。
- [x] **AC-8 登录过期有解释**：非用户主动登出导致的 401，登录页出现一次性提示「登录已过期，请重新登录」；主动登出、首次访问、启动时网络失败均不出现。
- [x] **AC-9 未知地址有出口**：任意未注册路径（如 `/practise`）渲染「这个地址不存在，可能是链接过期或拼写有误」+「回首页」；已登录态也保持壳层可导航。
- [x] **AC-10 战绩不再有死路**：筛选到 0 条时筛选条仍常驻，出现「「笔试」还没有已完成的记录」+「看全部记录」，点击清空筛选并回到第 1 页。
- [x] **AC-11 不回归**：类型检查、lint、全量测试、生产构建通过；不改 `api/types.ts`、不改后端、不新增错误码、不新增视觉 token。

## 交互与文案（逐字）

| 场景 | 文案 | 组件 |
| --- | --- | --- |
| 登录页过期提示 | 登录已过期，请重新登录 | `InlineError`（`variant` 复用现有错误条，不带重试） |
| 恢复成功 | 已恢复你上次未提交的作答（{formatWhen} 保存，精确到分钟） | `.sc-meta-line` + 关闭按钮 |
| 草稿过期 | 上一份未提交的作答已超过 24 小时，已清除 | 同上，一次性 |
| 草稿损坏 / 卷面不符 | 上一份未提交的作答无法恢复，已清除 | 同上，一次性 |
| 404 | 这个地址不存在，可能是链接过期或拼写有误 | `EmptyState` +「回首页」 |
| 战绩筛选空 | 「{类型}」还没有已完成的记录 | `EmptyState` +「看全部记录」 |

时间格式复用 `lib/format` 的既有口径，不在页面里手拼。

## 非目标与边界

- **不做 SPA 返回拦截**。当前 `BrowserRouter` + react-router 6.26 无 `useBlocker`（数据路由才有），
  手写 `popstate` 回推既脆弱又与路由自身监听打架。本需求选择「不拦你，但保证丢不了」：
  返回后草稿仍在，再进页面自动接上。代价是离开时没有确认弹框，**这是有意的取舍**。
- 不做笔试历史复核（需要后端补 `GET /api/exams/{run_id}` 只读端点，单独立项）。
- 不做请求超时、报告逐题复盘静默失败、雷达错误态、画像编辑草稿、图片简历预览等 P1 项（见文末）。
- 不改品牌文案与国风命名，不改列表 / 表单视觉，不引依赖，不改 `main.tsx` 路由形态。
- 不与工作区并发需求抢文件：本需求只认领上列文件。
