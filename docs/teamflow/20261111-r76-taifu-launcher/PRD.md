# r76 · 太傅悬浮入口（可拖拽参谋）

## 背景

用户提出三件事，顺序递进：

1. 「想做个类似于个人助手的那种 agent，可以通过对话的方式让 AI 分析用户的数据」——希望有一个能读懂站内记录、直接回答「先补什么 / 为什么 / 怎么补」的参谋，而不是让人自己在 8 个页面之间拼结论。
2. 「就叫太傅怎么样」——命名求意见。
3. 「可以做到右下角一个可拖拽的那种，而不是放到菜单或者导航里面」——入口形态必须是全局悬浮件，不能是第 16 个导航项。

第 4 句是**否决反馈**：「图标有点丑」——第一版圆形蓝底单字方案 A 被否，需要重做视觉。

本轮交付范围由用户最后一句「好，按照你推荐的做」界定为**方案 A（青玉方印）+ 可拖拽悬浮壳**：
先把入口打磨到能与既有「朝堂 / 科举」隐喻自洽、且不撒谎的程度，问答能力另立需求。

## 命名判断（用户提问的直接回答）

「太傅」可用，但要定成**参谋**而不是**老师**：

- 与产品既有隐喻同源（投卷 / 立传 / 召对 / 科考 / 医案 / 国子监），不像外挂一个 ChatGPT 头像那样突兀。
- 「太傅」是辅政之位，天然是「替你看账、给你判断」，不是「教你做人」。定位写成「你的跃迁参谋」，避免变成说教型 AI。
- 反例是「师父 / 先生 / 老师」——会诱导产品往「讲课」漂移，与本产品「用证据说话」的路线冲突。

## 目标

> 让参谋随时够得着，但**不占导航、不挡内容、不假装能力**。

三条可检验的用户结果：

- 任何页面右下角都有一个安静存在的入口，想用时一伸手就到，不想用时不会误触。
- 它可以被拖到不挡视线的地方，并且**下次回来还在那儿**（同一账号）。
- 点开后看到的是「它以后能干什么」，而不是一段伪造的 AI 回答。

## 用户故事

- 作为正在看诊断报告的用户，我想就地追问「这条短板是什么意思」，而不是切到另一个页面重新描述一遍我的情况。
- 作为习惯把工具栏拖到左上角的用户，我希望印章能跟着我走，而不是永远钉在右下角挡住按钮。
- 作为触屏用户，我不想在滑页面时把浮标拖飞，也不想它挡住底部安全区里的操作。
- 作为还没配 Key 的用户，我不希望点开一个「AI 助手」看到编造的分析——宁可被告知「还没接」。

## 验收标准

- [x] **AC-1 默认位置**：登录后右下出现 56×56 方印，右 24 / 底 88（避开右下 Toast 的 24），不覆盖主内容与顶栏。
- [x] **AC-2 可拖拽且不误触**：鼠标左键与触屏均可拖动；位移 < 5px 仍判定为点击（展开浮窗），拖拽结束的 click 不重复触发展开。
- [x] **AC-3 拖出视口即夹紧**：任意方向拖到底，印章始终保留 8px 边距完整可见。
- [x] **AC-4 位置记忆按账号隔离**：位置写入 `sc.taifu.pos.<userId>`；刷新、站内跳转、重登后恢复；换账号不复用上一位用户的位置；损坏 / 旧版本 / 非法数值降级为默认位置且不报错。
- [x] **AC-5 键盘可用**：印章聚焦后方向键 8px、Shift+方向键 24px 微调，「归位」或 Home 回右下；微调同样落盘。
- [x] **AC-6 桌面浮窗不压印章**：浮窗优先在印章上方展开，上方不足转下方，上下都不足时按空间大的一侧缩高（内部滚动），任何情况下与印章保持 12px 间距、不重叠。
- [x] **AC-7 窄屏底部面板**：≤640px 时浮窗改为底部面板（左右 12、底部叠加安全区、高度 `min(72dvh, 600px)`），无横向滚动；打开时印章淡出，关闭后恢复。
- [x] **AC-8 层级正确**：印章与浮窗 `z-index: 15`，高于 topbar（10）、低于 Toast（20）与 Modal（40），Toast 与确认弹窗不会被挡。
- [x] **AC-9 收起路径完整**：Esc、点击浮窗外部、路由变化（含 `/learn/:id` 这类子路径）均收起浮窗；Esc 收起后焦点回到印章。
- [x] **AC-10 窗口变化自适应**：窗口缩放、移动端地址栏收放（`visualViewport`）后位置重新夹紧，不会留在视口之外。
- [x] **AC-11 不伪造能力**：问答未接入，面板标「入口预览」，输入框与发送按钮 `disabled`，正文与脚注写明「接入后默认只读站内记录，不替你修改画像或自动投递」。
- [x] **AC-12 不进导航**：入口只在登录后的全局壳层挂载，不新增路由、不进侧栏 / 菜单 / `ToolNav`，未登录不渲染。
- [x] **AC-13 不回归**：`typecheck` / `lint --max-warnings 0` / `npm test` / `npm run build` 全过；未改后端、HTTP 契约、`api/types.ts` 与既有页面逻辑。

## 非目标（本轮明确不做）

- **不接问答接口**：不写后端 route、不调模型、不存对话历史。面板只说以后能做什么。
- **不做写操作**：不改画像、不触发投递、不代替用户提交任何东西。
- **不做全局状态面板**：不做「今日待办 / 连续打卡」这类常驻信息条，避免变成第二个仪表盘。
- **不做移动端悬浮手势**（长按、双击吸附）：先把拖拽 + 底部面板做稳。
- **不改 r69–r74 已定视觉**：只在 `base.css` 追加新段，不动既有类。
