# r81 · 太傅：长期记忆（跨对话的「你是谁」）

## 背景

r80 给了太傅**线程摘要**：把被窗口挤出去的早期对话压成一段要点。但它有两个天然边界：

1. **清空对话就没了** —— 用户点「清空对话」，摘要跟着删（这是对的：那是在清这次聊了什么）；
2. **只活在一个线程里** —— 太傅是单线程，但如果用户隔一周回来重开一段，上一段说过的事全丢。

于是出现一类反复发生的浪费：用户每次都要重新交代「我只能周末学」「我已经排除算法岗了」「我更想留在杭州」。
这些是**跨对话仍然成立的事实**，不是某次对话的上下文。档案里也没有它们——
画像只有技术栈与项目，简历只有经历，没有「你的时间约束」和「你的取舍」。

r80 的摘要放不下这类东西：它随时会被重写、会被清空、长度只有 240 字且必须概括整段对话。

## 目标

> 太傅记得住「你是谁」，而且用户随时能看到它记住了什么、能一条条抹掉。

## 三种上下文的分层（本轮定稿）

| 层 | 来源 | 生命周期 | 能否当引用 | 用户可见 |
| --- | --- | --- | --- | --- |
| 档案 | 服务端每次重读库里记录 | 与业务数据同寿 | **能**（白名单） | 各页面本来就能看 |
| 长期记忆 | 模型从对话里提炼，服务端去重后落库 | 跨对话，直到用户忘掉 | 不能 | **能**（记忆列表） |
| 线程摘要 | 模型滚动重写 | 随对话，清空即清 | 不能 | 不能（用户看的是回答） |
| 当前页面 | 前端传 pathname，闭集校验 | 一次请求 | 不能 | 面板顶部「当前：医案」 |

四条都是「模型能看到的信息」，但**只有档案是依据**。这条边界从 r78 一路守到 r81，本轮不变。

## 范围

| 改动 | 说明 |
| --- | --- |
| 模型输出 | JSON 增加 `memories`（新事实候选，每条 ≤80 字，每轮最多 2 条） |
| 存储 | 新表 `taifu_memories`（多条、按账号隔离、上限 20 条淘汰最旧） |
| 净化 | 压单行 → 长度夹取 → 与已有条目/同批**互相包含即同一件事**去重 |
| 提示词 | `【长期记忆】` 编号清单；空时给固定占位 |
| 可审计 | `GET /api/taifu/memories`、`DELETE /api/taifu/memories/{id}`、`DELETE /api/taifu/memories` |
| 界面 | 面板内「记忆 · N 条」入口，展开才读；每条可「忘掉」；「全部忘掉」两步确认；本轮记住新事实时当场告知 |
| 字段更名 | r80 的 `memory`（摘要）→ `summary`，避免与 `memories` 只差一个字母、模型输出错形状 |

明确不做：不做记忆编辑（只能忘掉重记）、不做「记忆来源回溯」（不记这句话是从哪一轮提炼的）、
不做跨账号/团队共享记忆、不做向量检索（20 条以内直接全量进提示词）。

## 验收标准

- [ ] **AC-1 只记稳定事实**：提示词要求「只有跨对话仍成立、且档案与长期记忆里都没有的事实/偏好」才进 `memories`；「这一轮问了什么」和「你的建议」都不算。
- [ ] **AC-2 与线程长度无关**：第一轮说了「只有周末有空」就该记住——不要求线程溢出（与 r80 摘要的门槛不同）。
- [ ] **AC-3 不记重**：与已有条目或同批条目互相包含即视为同一件事，只留第一条；同一句话第二次说不会多一条。
- [ ] **AC-4 有上限**：单账号 20 条，超出淘汰最旧；每轮最多新增 2 条。
- [ ] **AC-5 记忆不是依据**：白名单仍只由档案段构成；模型引用只在记忆里出现的 href → 丢弃并计 `dropped_citations`。
- [ ] **AC-6 可审计、可删除**：`GET` 列出全部；单条删除幂等（删不存在的 id 返回 0 不报错）；全部删除后列表为空。
- [ ] **AC-7 两种清空语义不同**：清空对话**不**清长期记忆；忘掉全部记忆**不**清对话。
- [ ] **AC-8 不回归**：r77–r80 的引用白名单、页面上下文、锚点、两步清空、空档案出口、线程摘要全部不变；两端全绿。

## 已知限制

- 记忆质量取决于模型自觉：它可能漏记（该记的没记），也可能记了一句其实不跨对话的话。程序只能管长度、去重、条数与引用边界，管不了「这句话值不值得记」。
- 去重是字面包含判断，不做语义相似：「我只有周末有空」与「工作日完全没时间」会被当成两条。
- 20 条上限按时间淘汰最旧，不按重要性：早期记的重要约束可能被后来的琐事挤掉。
- 没有编辑：记错只能忘掉再让它重记，且重记要看模型下次是否愿意再说一遍。
