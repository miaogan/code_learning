# r112 · 报告回收对岗缺口

## 用户目标

r110 建立对岗、r111 让缺口进入出题，但闭环在报告页断了：用户看到「本场设定：后端工程师 · 1-3年 · 国内 · 中型」，却看不出**这场为什么问这些题**。本轮把对岗带入的缺口词回收到报告页（以及历史行、会话顶）的「本场设定」，让 JD → 召对 → 医案三处口径一致。

## 范围

- `settingsLine`（本场设定唯一格式化入口）在四项 + 方向之后追加 `缺口：A / B / C`：
  - 只取前 3 项，空数组 / 空白项不产生空段；
  - 旧 run 没有 `focus_gaps` 键 → 文案与改造前逐字一致；
  - 报告顶、历史行、会话顶三处同时生效（共用同一入口，不新增第二份口径）。
- 不改任何后端：`Report.interview_settings` 与 `RunSummary.interview_settings` 均由 `rules.settings_or_none` 从 `payload.settings` 投影，r111 的 `focus_gaps` 已自动带出。

## 非目标

- 不新增报告字段、不改报告写入口径、不重算分数。
- 不新增页面区块（不再造一行「本场缺口」），避免与「本场设定」重复。
- 不把缺口命中包装成掌握度或评分。

## 验收标准

1. `settings.focus_gaps` 非空 → 设定行末尾出现 `缺口：A / B`；超过 3 项只显示前 3 项。
2. `focus_gaps` 为空数组 / 全空白 / 缺键 → 文案与 r111 前完全一致。
3. 报告页、历史页、会话顶使用同一函数输出，三处文本一致。
4. 前端 typecheck / lint / 测试全绿。
