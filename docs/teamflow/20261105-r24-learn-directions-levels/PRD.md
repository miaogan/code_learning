# PRD · 学习模块补齐方向 + 难度二级筛选（r24）

## 1. 背景

`20261105` 上线的站内教程（`/learn`，见提交 `86e07d3`）只覆盖 5 个方向、10 章，而题库 `backend/app/seed/questions.json` 有 **8 个方向 1088 题**。其中 **中间件与运维 151 题、SQL 与数据库 62 题、研发工程实践 50 题**（共 263 题，占 24%）在练习页能刷、在报告页会被推荐，但点进「站内教程」是空的——短板 → 学习的链路在这三个方向断掉。

同时，教程此前只有方向一个维度，无法回答「我是新手，先读哪章」。用户需要按难度分层阅读。

## 2. 目标

1. **方向补齐**：教程覆盖题库全部 8 个方向，每个方向 3 章。
2. **难度分层**：每章带唯一难度档位（基础 / 进阶 / 高级），目录页支持「方向 → 难度」两级筛选，筛选状态可分享、可刷新复现。
3. **三档齐全**：每个方向 基础 / 进阶 / 高级 各一章，二级筛选项点进去必有内容。
4. **顺序可推导**：目录顺序 = 方向顺序 × 难度顺序，由元数据排序得出，内容文件追加位置无关。

### 3.2 交互

- 一级筛选「方向」：全部 + 8 个方向（chip 单选，选中加 `✓`）。
- 二级筛选「难度」：全部 + 当前方向真实存在的档位（现为三档），随一级变化。
- 切换方向 **清空**二级选择（避免「新方向没有该档位，但按钮还亮着」）。
- 筛选态只存 URL：`/learn?direction=后端&level=进阶`；默认值不落参数；非法值回落 `all`。
- 卡片显示方向、难度、节数；空结果给出原因句 + 一条出路。
- 文章页面包屑与 meta 行显示难度，面包屑回到「同方向 + 同难度」的目录。
- 目录顺序与上一章/下一章统一由 `ALL_TUTORIAL_CHAPTERS`（按方向 × 难度排序）决定。

### 3.3 不做（本轮）

阅读进度 / 已读标记、全文搜索、章内 TOC、章内练习嵌入。均记录在案，进后续需求。

## 4. 验收标准

- AC-1 `TUTORIAL_DIRECTIONS` = 8，与 `questions.json` 的 direction 取值完全一致；每方向 ≥2 章（实际 3 章）。
- AC-2 每章 `level` ∈ {基础, 进阶, 高级}；每方向三档齐全；全库三档数量均衡。
- AC-3 目录页两级筛选可用，URL 可复现；`?level=中级` 这类非法值回落 `all`，不白屏。
- AC-4 任选方向 + 任选档位，结果非空；空结果有原因句与出路链接。
- AC-5 目录顺序按「方向 → 基础/进阶/高级」单调排列，内容文件追加位置不影响展示顺序。
- AC-6 内容完整性（每章 ≥3 节、小节 ID 唯一、末节带自测、表格列数对齐）由测试兜住。
- AC-7 类型检查、lint、单测、构建全绿；练习页筛选（复用同一 `ChipRow`）零回归。
