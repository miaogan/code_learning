## 0. 观感规格（先读本节，实现细节都在这里）

### 0.1 基调（一句可执行）

**「一场面试是一条往下长的时间线，不是一叠待办的卡片」**：面试官在左、你在右，每答完一句，分数与点评就长在你那句话的**同一个气泡里**（不弹窗、不折叠、不换页）；题号只回看已问过的（绝不预告下一题）。形制沿用产品的深色扁平面：**1 强调色 + 3 语义色**，靠 1px 边框与气泡左右对齐分层，**不加头像插画、不加气泡尖角、不加渐变与发光、不加卡片位移动画**。配置一屏像一张**一次性授权单**：四项一排一个控件、来源标注清楚、底部一句「不写回画像」。

### 0.4 动效 · 加载 / 空 / 错误

- **新气泡入场**：`opacity 0→1` + `translateY(8px)→0`，`--base` 180ms `--ease`；**只有本轮新增的 1–2 条气泡参与动画**，历史气泡一律静态呈现（恢复会话时**不 stagger、不重播**，否则长会话像闪屏）。
- **评分区出现**（AC-5）：整块 `opacity 0→1` 180ms；得分数字沿用 `ScoreBadge` 的 600ms ease-out 计数（0 → 目标），档位词与点评随数字一起淡入；`prefers-reduced-motion: reduce` 时直接给终值。
- **轮次占位泡**：提交后立刻在面试官侧插入占位泡（三点脉冲 + 「已用 Ns」）；服务端返回后**原地替换**为真实气泡（`opacity` 180ms），不出现「先消失再出现」。
- **滚动锚点**：新增内容后滚到「最后一条候选人气泡的评分区底部完整可见」的位置；用 `scrollIntoView({block:'nearest'})` + 气泡 `scroll-margin-bottom: var(--iq-scroll-pad)`、顶部 `scroll-margin-top: calc(var(--topbar-h) + var(--sp-3))`；动画 `smooth`，减少动效时 `auto`。**禁止滚到页面最顶**、禁止插入内容时整屏跳动。
- **滚动区不抖**：轮次进行中不重排历史气泡（不给历史泡加宽度/高度动画）。
- **配置 → 对话切换**：配置卡 `opacity 0→1` 反向淡出 120ms + 会话区 180ms 淡入；不做缩放、不做位移。
- **加载**：
  - 开局 `PhaseLoader` 三段：「读取本场设定 → 生成面试计划 → 准备第一问」（**禁止只有转圈**）。
  - 恢复会话（`GET /api/interviews/{run_id}`）`PhaseLoader` 一段：「正在恢复本场会话」。
  - 单轮评分中：占位泡（不使用全屏 loader，已答内容始终可见）。
- **空 / 错**（全部中文，不出现英文异常文案，AC-13）：
  - 无画像：沿用 `EmptyState`（原因 + 「上传简历」主按钮），沿用 r5 前的文案口径不改。
  - 开局无 Key / AI 不可用：配置卡内 `InlineError`「模型服务暂不可用，可稍后重试」+ 「重试」；**保留用户已填的四项值，不重置表单**。
  - 单轮失败或超时（AC-10）：`InlineError` 固定在输入区**上方**（不进入气泡流，不产生幽灵下一条发言）；答案**留在 textarea**；主按钮回到「提交回答」，可直接重试；重试成功覆盖同一 `question_id` 的分数。
  - 恢复失败（AC-9）：`InlineError`「无法恢复本场面试」+ 「重新读取」+ ghost「开新一场」。
- `prefers-reduced-motion: reduce`：全部时长 0，仅保留 opacity 的即时变化与最终态。

### 0.5 几何自洽（新尺寸逐条核算，改值必须重算）

1. **输入区 156 / 作答框 84 / 底部留白 172**：84 = 3 行 22（66）+ padding-y 8×2（16）+ 边框 1×2（2）；156 = padding-y 12×2（24）+ 84 + gap 8 + 按钮行 40（`--btn-h` 40 = 22 + 8×2 + 1×2，r1 §0.7）；172 = 156 + 16 ✓。作答框超过 5 行（占 128，与 `--textarea-min-h` 同高）后**框内滚动**，输入区高度不再增长，故粘性区高度有上界、永不遮住整屏。
2. **评分区最小 88** = padding 8×2（16）+ 行一 24（徽章/档位词 24 决定）+ gap 8 + 点评 2 行 40（13/20）= 88 ✓；点评上限 120 字，在气泡可用宽 640 − 24（padding）= 616、13px 下约每行 47 汉字 → 最多 3 行，评分区实际高 108 ≤ 无上界（内容驱动，`min-height` 只保证「答完立刻看得见一行分 + 两行点评」）。
3. **得分徽章 104**：等宽 16px advance 0.6em = 9.6px/字符；最长串「10.0 / 10」9 字符 = 86.4 + padding 8×2 = 102.4 ≤ 104 ✓（最小宽防抖，绝不出现串宽撑破）。行高 19 ≤ 徽章高 24 ✓。
4. **档位词 24**：2 汉字 × 12 = 24 + padding 8×2 = 40，pill 高 24 ✓，与徽章同行基线对齐。
5. **气泡内环不参与**：本轮气泡内**不使用 56 / 64 环**（环只用于结束态均分）；56 环内「10.0」4 字符 38.4 宽、19 高，半对角 √(38.4²+19²)/2 = 21.4 ≤ 内半径 23（56 − 5×2）✓（沿用 r1 §0.7-2 的算法，此处重算以证不冲突）。
6. **气泡 640** = `--iq-col-w` 720 − 80（左身份缩进 56 + 右侧留白 24）✓；正文 14/22，可用宽 616 → 每行约 44 汉字，≤45 可读，且比 r1 的 1080 满宽更适合「一句话一条」。
7. **内容列 720 与页面留白**：`--content-max` 1080 − 左右 padding 24×2 = 1032；1032 − 720 = 312 为右侧留白。列**左对齐**（与 `.sc-page-header` 标题同左基线，不做居中）✓；**不与 r3 的 628 + 24 + 380 双栏冲突**（面试页无右栏）。
8. **历史页面试卡 112** = r3 `--tl-row-h` 88 + gap 8 + 设定行 16 ✓；`--tl-scroll-h` 528 **不变**（它是固定可视窗的 max-height，不因卡高变化重算）：混排时 528 内可见约 4 条 112 + 1 条 88，仍只在窗内滚动，不撑爆页面主滚动。设定行 `white-space: normal`（不截断、不省略），岗位名极端 40 字时可增至 2 行，卡高用 `min-height: var(--tl-row-h-lg)` 而非固定高，**内容永不被切**。
9. **390 窄屏无横向滚动**（AC-18）：视口 390 − 页 padding 24×2 = 342；配置卡 padding 16 → 内宽 310。**工作经验 5 档** chip 宽（13px：「应届」50、「1-3年」61、「3-5年」61、「5-10年」68、「10年以上」79，含 padding 24）合计 319 + 4 gap 32 = 351 > 310 → **换行**（≥310 时 4+1，更窄时 3+2），每档 `white-space: nowrap`、不截断、不缩字号；**市场 4 档 / 规模 3 档**合计 224 ≤ 310 单行 ✓。气泡最大宽 `88%` = 273 → 每行约 19 汉字，仍可读。
10. **设定摘要条** 常态 48（`--merge-bar-h`）= 1×2 + 12×2 + 22 ✓ 单行；390 下四项约 300 > 310 临界 → 允许换到 2 行（高 68 = 1×2 + 12×2 + 22×2，用 `min-height` 自适应），**不截断不省略**。
11. **阵型冲突声明**：1–10 互不冲突。粘性输入区（156）与页面底部留白（172）保证最后一条气泡的评分区可完整滚出；气泡 `--iq-bubble-max` 与内容列 720 的组合在窄屏退化为 88% 百分比，仍留左右对齐差 12%（≈33px）足以区分发言人。

### 0.6 本产品新增禁止项（anti-patterns · r5）

- **一次铺开多题**：首屏出现 >1 条面试官气泡、或在页头保留「Q1–Q8」进度徽章条 / 题目列表数组——那只是把卷子换成气泡样式（PRD 反面目标 1）。**`InterviewPage` 现有的 `.sc-chips` 逐题进度条必须删除**，只留「已推进 N 轮 · 已答 M 题」纯计数（不含未来题号）。
- **评分不在原地**：点评被折叠到「查看评分」、飘到屏幕另一侧、或被推到滚动区外；或答完把分数做成弹窗 / 侧滑层。
- **用「卡片队列 + 下一题按钮」表达对话**：新一条必须**自动出现**，不得点「下一题」才翻页。
- **只靠颜色表达档位**：徽章必须有数字（0–10，一位小数）+ 中文档位词（良好 / 一般 / 薄弱），色盲可读（AC-18）。
- **新增颜色或裸色值**：三档只用既有 `--success` / `--warn` / `--danger` 与对应 tint/line token；CSS 注释里也不许出现色值字面量。
- 给气泡加**尖角、头像插画、渐变、发光、整泡点击**（对话是文本流，不做拟物社交气泡）。
- 配置表单开场后仍可编辑，或出现「保存到画像」入口（临时设定**永不**写回，AC-3）；表单未填就阻断开场（四项全空也必须能开始）。
- 禁用态用 `opacity < 1` 表达（会掉到对比度下限以下）：一律用底 `--bg-surface` + 字 `--text-tertiary` + 中文说明行。
- 输入区随页面滚走、或被粘性区遮挡最后一条气泡（AC-18「始终可达」）。
- 恢复会话 / 刷新时**重播整屏气泡动画**（stagger 重播会让长会话闪屏，也浪费 15s 预算）。
- 引入第三方聊天 UI / 动画 / SSE 库（PRD 非目标，AC-16 无新依赖）。

## 4. 交互规则补充（与 AC 强相关）

1. **配置不可中途改（Q3）**：`chat` / `ended` 下摘要条为**纯展示**（无输入、无编辑入口）；要改口径只能「重开一场」。恢复 `?run_id=` 时同理。
2. **临时值不落画像（AC-3）**：页面上任何位置（配置卡 / 摘要条 / 结束态）**都不出现**「写入画像」类控件；摘要条右端仅 12/16 `--text-tertiary`「临时设定，不改画像」。
3. **本轮失败零副作用（AC-10）**：失败不新增气泡、不清空 textarea、不改已答计数；`InlineError` 的「重试」复用同一次提交意图。
4. **刷新恢复（AC-9）**：`?run_id=` 载入 = 一次 `GET`；恢复后气泡条数 / 答案 / 分数与离开前逐项相等（视觉上首屏直接呈现，**无入场动画**）；已完成 → 只读态。
5. **点评逐字（AC-5）**：前端不得二次 `trim` / 截断 / 改写 / 自动补句号；`white-space: pre-wrap` 保留服务端换行。
6. **题号稳定（AC-8）**：`Q{n}` 由 `iq-N` 派生，刷新不变；不得按渲染顺序重排编号。
7. **中文文案（AC-13）**：所有可见错误文案为中文短句（≤24 字）+ 可重试提示；不出现英文异常、不出现端点 / 路径。
8. **键盘**：`Ctrl/Cmd + Enter` 提交；`Esc` 不触发任何提交；tab 可达且焦点环可见（全局 `:focus-visible`）。
9. **窄屏（AC-18）**：≤720 单列；配置 4 项纵向排列、chip 换行不截断；输入区仍 sticky 且不被键盘遮挡（`scroll-padding-bottom: var(--iq-scroll-pad)`）。

## 5. 无障碍要点

- **评分双通道**：得分徽章有数字（0–10，一位小数）+ 档位词（良好 / 一般 / 薄弱）；不给纯色块。
- **实时播报**：新评分区 `aria-live="polite"`，可访问文本「本题得分 7.5 分，满分 10 分，评价一般」；点评为独立段落紧随其后。
- **气泡语义**：每条气泡 `role="group"` + `aria-labelledby` 指向其身份行（「面试官，第 3 问」/「你的第 2 轮作答」）；题号 chip 用文本 `Q3`，不靠图标。
- **输入**：textarea `aria-label="你的回答"`；提交按钮文案随状态变化（提交回答 / 正在评分…）；失败条为 `role="alert"`。
- **焦点**：全局 2px `--accent` 焦点环 0ms 出现；sticky 输入区不遮挡被聚焦元素（`scroll-margin` 见 §0.4）。
- **文字对比**：一律沿用既有 token 的成对组合（正文 `--text-primary` on `--bg-raised` / `--bg-surface`；点评 `--text-secondary` on `--bg-inset`）；**禁止 `opacity < 1` 降文字**（禁用态用底 + 文案）。
- **窄屏 390**：`document.scrollWidth ≤ 视口宽`；气泡 `overflow-wrap: anywhere` 防长英文串撑破；chip `nowrap` 但容器可换行。
- **减少动效**：`prefers-reduced-motion: reduce` → 全部 0ms，保留最终态与 opacity。
