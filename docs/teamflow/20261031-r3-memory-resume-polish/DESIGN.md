## 0. 观感规格（先读本节，实现细节都在这里）

### 0.1 基调（一句可执行）

**「成长是刻度，改稿是底稿」**：时间线像一条安静的结算记录 —— 时间列、类型徽章、等宽指标横向对齐，靠 1px 边框与左 2px 状态条分层，不靠悬浮/阴影/渐变；润色页像编辑对稿 —— 原句与建议句成对出现、卡左状态条区分采纳/忽略、右侧窄栏单源成稿。两个新表面**不引入任何新颜色**（仍是 1 强调色 + 3 语义色），**不做卡片位移动画**（列表不许抖）。

### 0.4 动效 · 加载 / 空 / 错误

- **时间线进入**：每条 `opacity 0→1` + `translateY(8px)→0`，180ms；stagger 40ms/条，最多 6 条（总 ≤240ms）；第 7 条起不再延迟（直接出现）。
- **对比块展开**：高度 0→`--cmp-panel-h` 180ms + 内容 `opacity` 120ms；折叠 120ms。展开期间**其它事件行不动**（用绝对定位不动画，或用 `max-height` 只影响自身）。
- **采纳切换**：卡左状态条换色 120ms；成稿预览中被替换段落淡入 120ms + 左侧 `--accent` 条 1.5s 后 `opacity 120ms` 隐去；**转化列表不重排**（忽略项留在原位）。
- **成稿生成**：右栏原地切 `PhaseLoader`（三段文案「汇总已采纳条目 → 重写段落 → 拼装成稿」+ `elapsedSec`），**禁止只有转圈**；`elapsedSec > 20` 追加一行 12/16 `--text-tertiary`：「仍在生成 · 已用 24s；已采纳的 N 条不会丢失」；生成成功 180ms 淡入成稿，「重新生成」按钮回到可用。
- **加载 / 空 / 错**：
  - 时间线加载：复用 `PhaseLoader`（`title="正在读取成长时间线"`，`phases=['读取成长事件','对齐指标']`）；**不用骨架屏**（AI 以外但含服务端聚合）。
  - 时间线空态：`EmptyState` 原因「还没有成长记录 —— 完成一次面试或笔试，这里就会留下第一条」+ 主按钮「开始测评」`/exam`；下方 12/16 `--text-tertiary`「历史数据从本版本上线起记录」（Q6）。
  - 时间线失败：页内 `InlineError`（中文原因 + 「重新读取」）；失败**不得隐藏趋势表**。
  - 建议列表加载：`PhaseLoader`（「读取简历正文 → 生成逐条建议 → 事实校验」）。
  - 润色失败：对应区块内 `InlineError`（右栏失败不影响左栏已出建议；左栏失败右栏保持原状）。
  - 无画像/无简历：`EmptyState`（「先上传简历，才能做润色」+ 「上传简历」）。
  - `prefers-reduced-motion: reduce`：全部时长 0，仅保留 opacity 变化与最终态。

### 0.5 几何自洽（新尺寸逐条核算，改值必须重算）

1. **事件卡 88** = padding 16×2 + 第一行 24（类型徽章 24 决定行高）+ gap 8 + 第二行 24（短板 chip 24 决定行高）。行内元素全部 24 高，无额外 padding。
2. **时间线滚动区 528** = 上下 padding 20×2 + 5 条 × 88 + 4 × gap 12 = 40 + 440 + 48 = **528** ✓（5 条可完整可见，第 6 条起滚动；展开一条时同样只在区内滚动，不撑爆页面主滚动）。
3. **对比块** 常规 112 = padding 12×2 + 标题 16 + gap 8 + Δ 行 32 + gap 8 + chip 行 24 = 112 ✓；首次态 70 = 12×2 + 16 + 8 + 22 = 70 ✓。
4. **合并摘要条 48** = 1px 边框×2 + padding 12×2 + 正文行 22 = **48** ✓（与表格行高 48 同高，视觉上成行）。
5. **时间列 120**：时间文案「2026-10-31 21:04」16 字符 × 12px mono（advance 0.6em = 7.2px）= 115.2 ≤ 120 ✓ 余 4.8px（不折行、不省略）。
6. **建议卡最小 320**（内边距 20 已计入）＝ 20 + 标签 16 + 8 + 原句 2 行 40 + 12 + 标签 16 + 8 + 建议句 2 行 44 + 12 + 标签 16 + 8 + 理由 2 行 40 + 20 + 按钮行 40 + 20 = **320** ✓。原句/建议句超过 3 行时**截断 + 「展开全文」**（展开只增高本卡，卡内不出现横向滚动）；按钮行常驻卡底（`flex` 列，正文区可伸缩），永不因文本长出卡外。
7. **两栏 1032** = 左 628 + gap 24 + 右 380 = 1032 = `--content-max` 1080 − padding 24×2 ✓；**视口 ≥1320 用双栏**（1080+240 侧栏+48），<1320 单栏并把成稿区折叠为「成稿预览」按钮（展开为全宽 480 高面板）。
8. **成稿区 480** = Tab 40 + gap 12 + 预览 428 ✓；预览可用宽 348 = 380 − padding 32，13/20→14/22 正文每行约 24–26 个汉字（≤40，长句可读），**正文用 `--font-sans`，仅分数/年份/数字用 mono**。
9. **Δ 列 76**：24/32 mono 4 字符（「−0.4」）57.6 ≤ 76 ✓，5 字符（「+0.75」不存在，格式固定 1 位小数）也仅 72 ✓；事件行内 `--delta-w-sm` 52：16/19 mono 4 字符 38.4 ≤ 52 ✓。
10. **阵型冲突声明**：以上 1–9 互不冲突；`--sugg-min-h` 与 `--polish-pane-w` 的组合在 ≤3 行文本下不溢出（预算 320 ≤ 480 可视区），超长文本按 §0.5-6 截断，故不需要更高可视窗。

### 0.6 本产品新增禁止项（anti-patterns · r3）

- 时间线用**纯文字列表**、或让颜色单独承载类型/变化（必须有类型徽章文字、`↑/↓/＝` + 数字）。
- 展开对比时**其它行位移/列表抖动**；或展开把整页主滚动撑到两屏。
- 事件行里把「短板新增」画成红色感叹号墙：新增/消失各最多展示 3 项 + 「+N」，不做红黄满屏。
- 「历史」能力项用 `opacity < 1` 表达（会掉到 4.5:1 以下）——必须用徽章文字 + 分组标题。
- 建议卡做**整卡点击采纳**（误触率极高，只能点按钮，且按钮必须有文字态）。
- 成稿预览用等宽字体排正文；或把导出内容当"预览拼串"（导出/复制只取服务端 `markdown`）。
- 生成中只转圈、无阶段文案、无已用秒数；或生成中不拦离开（用户刷新丢采纳状态）。
- 把 `duplicate` 事件做成和普通事件一样显眼（重复上传会淹没真实成长节点）。
- 润色页把原句/建议句压成一行「原句 → 建议句」省略理由（用户"不敢用"的根因）。

## 4. 交互规则补充（与 AC 强相关）

1. **时间线键盘**：滚动区 `role="region"` + `aria-label="成长时间线，共 N 条"` + `tabindex="0"`；事件卡展开按钮 `aria-expanded` / `aria-controls`；展开后焦点移到对比块标题（`tabindex="-1"`），折叠后焦点回按钮。内部滚动区支持 ↑↓/PgUp/PgDn（不劫持页面滚动，`overscroll-behavior: contain`）。
2. **采纳/忽略只动预览**：不写 `documents.text`（AC-10）；不跨会话持久化；刷新后重跑。导出/复制/预览生成态一律取服务端 `markdown`，前端零 trim/replace/拼接（AC-11，沿用 r2 口径）；导出文件名规则不变（`简历润色-<原文件名>.md`）。
3. **生成中离开保护**：`ConfirmModal`（§2.4）；生成失败**不**清空采纳状态、不清空左栏。
4. **目标岗位重跑**：输入框默认显示画像 `target_role`；点「按此岗位重跑」→ 复用同屏 `PhaseLoader` 重跑建议（已采纳项按 `original_text` 保持映射，若 `original_text` 不变则保留采纳状态，否则回到未处理并提示「建议已变化，请重新确认」）；「恢复默认」清空输入并回显画像岗位；回显 chip「临时 / 默认」。画像 `target_role` 全程不变。
5. **未记录事件的可见说明**（AC-3）：历史页派生判断 —— `timeline` 中 `interview+exam` 事件数 < `history` 行数（两者同 `limit`、同倒序）时显示头部 warn 提示；不新增契约字段。
6. **步骤门禁**（沿用 r1 §4.3）：无简历时 `/polish` 与 `/history` 显示引导空态 + 主按钮，不重定向、不白屏。
7. **重复上传**（Q4）：事件标 `duplicate: true` → 事件卡右侧 chip「同一份简历」12/16，指标照常显示，弱化不隐藏。
8. **一次请求一个动作**：生成中禁用同类提交按钮，防重复扣费；建议与分析按钮各自独立 loading。

## 5. 无障碍要点

- **对比度**（沿用 r1 已算值，面底 `--bg-surface`）：`--text-primary` 14.9:1 / `--text-secondary` 7.8:1 / `--text-tertiary` 5.2:1 / `--accent` 6.6:1 / `--success` 7.6:1 / `--warn` 9.0:1 / `--danger` 5.8:1。新表面全部使用既有 token，不引入新色，故不降级；历史项**禁止**用透明度表达。
- **冗余编码**：类型用徽章文字；Δ 用「↑/↓/＝ + 数字 + 中文（提升/下降/持平）」；新增/消失短板用 `+`/`✓ 消失：` 前缀 + 文案；采纳状态用文字「已采纳/已忽略」+ `aria-pressed`，颜色只是辅助。
- **焦点**：所有可交互元素 2px `--accent` 焦点环 + 2px 偏移；滚动区内元素内偏移焦点环；Modal 内 Tab 循环、Esc 关闭、关闭后焦点回触发按钮。
- **播报**：采纳/忽略切换 `aria-live="polite"`（「已采纳第 3 条建议，成稿预览已更新」）；成稿生成失败 `aria-live="assertive"`；生成中阶段文案每秒更新已用秒数（`aria-live="off"`，避免每秒播报）；时间线加载完成播报「已加载 6 条成长记录」。
- **触控/缩放**：主操作 ≥40px，行内展开按钮 32×32 且外扩 8px 热区；文本放大 200% 时事件卡用 `min-height: var(--tl-row-h)` 允许撑高、第二行 chips 换行不裁切；建议卡按钮行常驻卡底不被文本顶出。
- **动效**：遵守 `prefers-reduced-motion: reduce`（§0.4）。
