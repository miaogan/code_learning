# 系统架构常见场景题库扩充

## 背景与目标

用户要求盘点当前题库，并继续补充「系统架构常见场景」方向的问题。盘点发现：原题库 1224 道中「研发工程实践」有 50 道，但既有二级方向「架构设计」为 0 道；缓存、幂等、限流、分库分表等主题散落在其他分类，没有形成可直接筛选的架构场景题组。

本轮补充 60 道原创客观题，帮助用户练习「给定业务约束如何选型、依赖失败如何兜底、一致性／可用性／容量／复杂度如何取舍」，而非只背架构名词。

## 范围

- 全部归入 `研发工程实践 / 架构设计`，`language=""`。
- 题型为 single 40 / multiple 11 / judge 9；难度为 basic 12 / intermediate 33 / challenge 15。
- 覆盖高并发读写、缓存一致性、重复请求与回调、异步任务、消息积压与乱序、分库分表、服务拆分、最终一致、故障降级、多租户、分布式锁、可观测性和容灾。
- 沿用 `staging → question_merge → seed → SQLite 幂等导入 → 练习／笔试` 链路，不新增页面、HTTP 字段、表结构或运行时 AI 调用。
- 不迁移或删除旧题，不修改工作区中与本需求无关的前端改动。
- 新题为原创练习，不是某个厂商的考试真题或生产故障复盘，不宣称覆盖全部架构知识。

## 验收标准

1. 题库 1224 → 1284，研发工程实践 50 → 110，架构设计 0 → 60；新题来源 `sys-arch`、ID `sysarch-001`…`sysarch-060`。
2. 60 道全部保留，题型／难度／必备度分布符合计划；答案属于选项，解析完整。
3. 与原 1224 道题无归一化字面重复，无字符 2-gram Jaccard ≥0.62 的近重复。
4. 合并和选项重排逐字节幂等；新增通用题导致的旧题选项轮转保持正确项文本及答案语义不变。
5. 隔离 SQLite 首次导入 1284，重复导入 0 新增；架构设计筛选 `limit=0` 恰返回本批 60 道、补位 0；三种客观题由既有判分函数正确判定。
6. 题库专项测试、全量后端测试与 ruff 通过，并如实区分其他未提交改动或环境问题。
