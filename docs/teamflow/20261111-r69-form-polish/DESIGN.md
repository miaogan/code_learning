# r69 · 表单与笔试开局视觉设计

## 设计方向

沿用 r38 的近黑底、酸柠绿、细描边与仪器面板语言。将下拉看作与按钮同级的「操作面」，而不是浏览器默认白色控件；标签是辅助信息，当前值是主体，焦点用酸柠绿明确指示。

## 公共下拉规格

| 项目 | 规格 |
|---|---|
| 标准下拉 | 高 `--btn-h`，内边距 `0 --sp-8 0 --sp-3`，正文 `--fs-body` |
| 紧凑清单筛选 | 桌面高 `--btn-h-sm`，正文 `--fs-small`；其余表面相同 |
| 表面 | `--bg-raised`，边框 `--border-strong`，圆角 `--radius-8` |
| 箭头 | 16px SVG，右缘 `--sp-3`；右侧预留 40px（右侧 32px + 图标与文字的 8px 空隙） |
| 悬停 | 边框 `--text-tertiary`，背景 `--bg-surface` |
| 键盘焦点 | 酸柠绿边框与 2px 实线 outline，2px offset，外加底色隔离环 |
| 禁用 | `--bg-surface`、`--text-tertiary`、弱边框；保留箭头，不用整体透明度削弱 |
| 移动端 | ≤640px 最小高 `--touch-min`，输入字号 `--fs-input-mobile` |

使用 `color-scheme: dark` 提示浏览器原生控件使用深色模式。`<option>` 提供深色兜底，但不伪造系统弹层。

## 尺寸推导

- 箭头 `--select-icon-size = 16px = 8 × 2`。
- 标准控件右侧预留 40px = `--sp-8(32)` + 文字与箭头的 `--sp-2(8)`。
- 箭头定位右缘 12px：40px 预留区 = 12px 右缘 + 16px 图标 + 12px 文字间隙；与统一右侧 padding 不冲突。
- 页头标题沿用 `--fs-section-title / --lh-section-title`，不新增字号。
- 页头说明最大宽沿用 `--iq-col-w`；表单/笔试配置最大宽沿用 `--qa-col-w`。
- 网格轨道 `--lab-rule = 1px` 仅补齐既有失效引用，不修改已交付布局尺寸。

## 笔试开局层级

1. `EXAM / SETUP` 等宽小标签 + 「按你的目标，组一场笔试」。
2. 当前画像的目标岗位、技能数、项目数。
3. 总题、客观题数量规则和本地判分说明。
4. 「组卷偏好」分区：方向 / 子方向 / 难度 / 题量。
5. 主按钮「开始笔试 ↗」与弱化的「先看看画像」。

不改变原生 label → select 关联；装饰箭头 `aria-hidden`。桌面四列，≤960px 两列，手机保留两列以缩短配置页纵向长度；按钮可换行。

## 页头

标题大小、说明文字对比度与分隔线统一，说明不再使用近似禁用文字的三级颜色。样式只针对工作台直接内容区的页头，避免波及登录页等特殊布局。

## 取舍

原生 `<select>` 的系统弹层无法完全定制。相比模拟 listbox，本方案少一层焦点、滚动、键盘搜索和移动适配逻辑，保住可访问性与既有业务行为。
