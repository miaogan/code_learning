# r69 · 页面表单视觉统一

## 背景与目标

用户反馈：「看看前端 页面优化一下 现在有点丑 特别是下拉框 格格不入」。

在现有近黑底、酸柠绿点缀的仪器面板主题内，统一原生下拉框的表面、边框、箭头、焦点与禁用状态；提高笔试开局配置区和全站页头的信息层级。不是另起一套主题，也不重做业务功能。

## 验收标准

- [x] 笔试、设置、版本对比、先锋采集和清单筛选的下拉使用一致的页面内视觉。
- [x] 保留原生 `select`：不伪造弹层、不接管键盘、读屏或移动端系统选择器。
- [x] 键盘焦点清晰可见；禁用控件保留箭头且可辨识。
- [x] 长文件名与长选项不撑出容器，不挤压箭头区域。
- [x] 桌面笔试筛选四列，≤960px 两列；≤640px 下拉至少 44px、字号 16px。
- [x] 笔试筛选值、方向 → 子方向联动、组卷参数和保存配置逻辑不变。
- [x] r69 产品文件完成时 typecheck、lint、全量测试、生产构建通过；后续工作区并发改动的类型阻塞见 `ACCEPTANCE.md`。

## 范围

- `frontend/src/styles/tokens.css`：箭头图形和尺寸 token，补齐既有网格轨道变量。
- `frontend/src/styles/base.css`：追加公共表单样式、页头和笔试开局样式。
- `frontend/src/pages/SettingsPage.tsx`：JSON 模式下拉接入公共类。
- `frontend/src/pages/ExamPage.tsx`：开局卡的标题、画像摘要、规则说明和分区。

## 非目标与边界

- 不更换 UI 框架、不引入依赖、不重写所有页面。
- 不承诺 `<option>` 弹层跨操作系统像素级一致，其外观由浏览器和系统决定。
- 不新增、修改 HTTP 契约、数据库或 AI 请求。
- 不覆盖工作区同时存在的雷达、练习及后端改动；本需求只认领以上四个前端文件及本任务文档。

## 已验证

真实 Chromium 渲染（演示数据，不使用真实凭据）覆盖设置、笔试、版本和先锋页；桌面 1440px 与移动 390px 均无横向溢出。使用浏览器原生键盘事件验证方向切换和焦点，非仅检查 CSS 源码。

验收细节与已知限制见 `ACCEPTANCE.md`。
