## 0. 视觉与观感规格（先读本节，实现细节全在这里）

### 0.1 基调（一句话可执行）

深色技术工具感：**深灰底 + 单一强调蓝**；分层靠 1px 边框与内嵌高光，不靠大面积投影；分数 / 时长 / 代码 / 题号一律等宽 + `tabular-nums`。全站只允许「1 个强调色 + 3 个语义色」，语义色只承担状态，绝不作装饰。

### 0.4 间距 / 圆角 / 描边

- 间距基数 4：`4 8 12 16 20 24 32 40 56`（`--sp-1`…`--sp-9`）。卡片内边距 20，页级纵向节奏 24/40，卡片间距 16。
- 圆角：`4`（chip、引用块）/ `6`（输入框、小按钮）/ `8`（按钮、Toast）/ `12`（卡片、Modal）/ `16`（上传区）/ `999`（pill 徽章）。
- 描边一律 `1px solid`；例外仅两处：`sourceQuote` 与错误条左侧 4px→**2px** 状态条、上传区虚线 `2px dashed`（`8 6` 节奏）。
- 布局尺寸（已核算）：顶栏 56，侧栏 240，主区 `max-width 1080`（含内边距 24）。完整双栏需视口 ≥1368；<1024 侧栏收起为顶部横向步骤条（高 40）。

### 0.6 动效 · 加载 / 空 / 错误态

**动效**

- 面试逐题切换：旧卡 `opacity → 0` 100ms；新卡 `translateY(12px)→0` + 淡入 180ms。切换后焦点移到新题卡标题、`scrollIntoView({block:'start'})`。
- 出分揭示：得分环从 0 走到目标 **600ms ease-out**；环内数字同步计数（mono+tabular，防抖动）；点评块延迟 200ms 淡入 180ms。
- 报告短板列表：stagger 40ms/项（最多 5 项 → 总 ≤200ms）。
- 路由切换：内容区 180ms 淡入；**不做整屏滑入**（长页会双滚动）。
- Toast：`translateY(8px)`+淡入 180ms，停留 2s，淡出 120ms。
- Modal：`opacity` + `scale(0.96→1)` 180ms；关闭 120ms。

**加载**

- 骨架屏**只用于 ≤800ms 可完成的结构**（卡片、表格行）：底 `--bg-surface`，内容条 `--bg-raised`，`1.2s` 呼吸（`opacity .5↔1`）。
- AI 调用（画像生成、出题、判分、报告）用**阶段文案**替代骨架：三段式步进文案（如「解析简历 → 提取技能 → 生成画像」），当前段前缀 3 点脉冲（1.2s 循环），右侧显示已用秒数（mono 12/16）。禁止只有转圈而没有任何文字进度。

**空态**：必须含「一句原因 + 一个主按钮」，禁止只写"暂无数据"。
例：报告短板不足 → 「本次未发现明显短板 —— 加做一轮更高难度的笔试」+ 主按钮「继续答题」；历史空 → 「完成一次测评后，这里会出现你的成绩趋势」+「开始测评」。

**错误态**：页内 inline 错误条（底 `rgba(242,104,107,.08)` + 左 2px `--danger` + 中文原因 14/22 + 次按钮「重试」）。禁止整页白屏、禁止只用 Toast 承载失败。上传类错误（空文件 / 加密 PDF / >10MB）就地显示在拖放区下方，且**不进入下一步**（AC-1）。

**减少动效**：`prefers-reduced-motion: reduce` → 全部时长 0，仅保留 opacity 变化，计数直接显示终值。

### 0.7 几何自洽校验（写死推导，禁止再改尺寸而不复算）

1. **面试计时环**：直径 64，描边 6 → 内半径 `r = 32 − 6 = 26`。内部文本上限「99:59」= 5 字符 × 13px mono（advance 0.6em = 7.8px）= 39px 宽，行盒高 16px → 半对角 `√(19.5² + 8²) = 21.1px < 26` ✓ 余量 4.9px。若内字号提到 16px（advance 9.6，宽 48），半对角 `√(24² + 9.5²) = 25.8 < 26` ✓ 仍成立。
2. **得分环**：直径 56，描边 5 → 内半径 `r = 28 − 5 = 23`。环内文本 ≤3 字符（"10"、"8.5"，16px mono，宽 28.8，行盒 19）→ 半对角 `√(14.4² + 9.5²) = 17.3 < 23` ✓ 余 5.7；即使 4 字符 "10.0"（38.4×19）半对角 `21.4 < 23` ✓。显示规则取 ≤3 字符（不带单位）。
3. **严重度徽章**：高 24 = 行高 16 + padding-y 3×2 + 边框 1×2 = **24 恰合**，不再追加任何 padding。
4. **统计磁贴**：高 96 = padding 16 + 标签行 16 + gap 8 + 数值行 40 + padding 16 = **96 恰合**；三枚同高，数值字号不得 <28px（否则留 8px 空白）。
5. **主按钮**：高 40 = 行高 22 + padding-y 8×2 + 边框 1×2 = **40 恰合**。
6. **textarea 最小高**：128 = 5 行 × 22 + padding-y 8×2 + 边框 1×2 = **128 恰合**。
7. **课程卡**：132 = padding 16×2 + 标题 24 + gap 4 + 描述 2 行 40 + gap 8 + 元信息行 24 = **132 恰合**（元信息行含 24px 难度徽章）。
8. 环 56 与徽章 24 同排：垂直居中于同一 56px 行高内 ✓。

**冲突声明**：以上 8 条互相一致，无两处不一致的尺寸。若后续改动任一尺寸，必须重算对应行并在此更新，不得只改 CSS。

### 0.8 本产品禁止项（anti-patterns）

- **纯平无边框方砖**：深色底上，卡片 / 输入框 / 磁贴必须有 1px 边框或内嵌高光，否则视觉消失（唯一例外：inset 提示条用底色 + 左 2px 状态条）。
- 大面积蓝紫渐变、玻璃拟态、霓虹光效：破坏「技术工具」感；强调色只出现在焦点 / 激活 / 主按钮 / 进度。
- 可点击元素无 hover 反馈（课程外链卡、题目卡、可删 chip、表头箭头）。
- 分数 / 时长 / 题号 / 列数值用非等宽字体或非 tabular → 数字跳动、列不对齐。
- 同一屏幕出现 ≥2 个强调色元素，或语义色用于装饰。
- 红/绿作为**唯一**状态信息：对错、严重度必须同时带文字或符号（✔/✗、"高/中/低"）。
- 逐题页使用长对话气泡流（首版为逐题单屏卡）。
- 骨架屏空转 >800ms 却没有任何阶段文案或已用时。
- 空态只写"暂无数据"；错误只用 Toast；主流程放进全屏 Modal（上传 / 面试 / 笔试均为页内状态）。

## 4. 交互规则补充（与 AC 强相关的细节）

1. **失败不丢输入**（AC-3、AC-4）：答题页任何 AI 失败只影响「出分」，文本框与已选项永不清空；「重新作答」也预填原答案并可查看原得分。
2. **一次请求一个动作**：提交中主按钮转 spinner 并禁用同屏其它提交类操作，防重复扣费与重复计分。
3. **步骤门禁**：未上传简历时点面试/笔试/报告 → 目标页显示引导空态 + 主按钮「上传简历」，不重定向、不白屏。
4. **外链**：全部新标签 + `rel="noopener noreferrer"`；清单缺链的课程卡置灰（字 `--text-tertiary`）并标注「链接待更新」，不出 404（呼应 anti-goal 4）。
5. **本地持久化提示**：任何写库失败都在顶栏状态区变为「未保存 · 重试」`--danger`，而不是只弹一次 Toast（AC-7 刷新不丢）。
6. **无密钥可见**（AC-8）：前端不出现任何 Key 输入框、不显示模型名与端点；设置页仅展示「AI 服务：已连接（服务端配置）」。

## 5. 无障碍要点

- **对比度（已算，面底 `--bg-surface` #141A23 为基准）**：`--text-primary` 14.9:1、`--text-secondary` 7.8:1、`--text-tertiary` 5.2:1、`--accent` 6.6:1；主按钮 `#06121F` on `--accent` 7.1:1；`--danger` 5.8:1、`--warn` 9.0:1、`--success` 7.6:1。徽章用「12% 同色底 + 35% 同色描边 + 原色文字」，在上述面底上仍 ≥4.5:1。
- **焦点**：所有可交互元素必须有 2px `--accent` 焦点环 + 2px 偏移；禁止 `outline: none` 而无替代；卡片级焦点环套外沿，内层 chip 用 1px 内偏移避免嵌套冲突。
- **键盘**：上传区为 `button`（Space/Enter 打开文件选择）；chip 删除为独立 24×24 按钮并带 `aria-label="删除技能 React"`；Modal 内 Tab 循环、Esc 关闭、关闭后焦点回触发按钮；逐题切换后焦点落新题卡标题（`tabindex="-1"`）。
- **冗余编码**：严重度、对错、成绩变化一律「文字/符号 + 颜色」，颜色永不单独承载信息。
- **播报**：出分结果 `aria-live="polite"`；提交失败 `aria-live="assertive"`；计时环 `aria-hidden="true"`（作答不计时限，无需播报）。
- **触控与缩放**：主操作高度 ≥40px，行内图标按钮 32×32 且外扩 8px 热区；字号以 rem 计（根 16px），文本放大至 200% 时卡片用 `min-height` 允许撑高、不裁切。
- **动效**：遵守 `prefers-reduced-motion`（见 §0.6）。
