# RAG 三态检索评测报告

> 生成命令：`python -X utf8 scripts/eval_rag.py` ｜ 金标复用 `question-retrieval-gold.json`（version `v1`）｜ embedder `hash-bigram-256`（engine `pgvector`）｜ 样本量 n = 20
>
> 所有数字来自**直连 PostgreSQL** 真实执行 `services/retrieval/hybrid.py` 的结果，非手写。
> 检索对象是 `rag_chunks`（题库 chunk），命中按 `chunk.ref_id`（= 题目 id）对账。

## 口径说明

- 三态：keyword = chunk 正文 ILIKE；semantic = 向量余弦 top-K；hybrid = 两腿 RRF（k=60）融合。
- 默认 embedder 是离线 HashingEmbedder：其「语义」是字符 bigram 重叠（模糊关键词基座），**不是语义模型**；配置 `AI_EMBED_MODEL` 后本脚本零改动即评真实语义。
- 门禁：hybrid recall@5 ≥ 70%，且不比 keyword 回退超过 5 个百分点（融合的意义是「至少不比单腿差」）。
- 标注集由题干关键词启发写成，存在标注泄漏；只用于回归检测，不是能力宣传。
